# قياسات Qiyasat — النسخة التأسيسية 0.1.0

## ما الموجود في هذه المرحلة؟
- مشروع Android أصلي بلغة Kotlin.
- إعداد ARCore بوصفه ميزة اختيارية (AR Optional).
- فحص أولي لتوافق الجهاز مع ARCore عند تشغيل التطبيق.
- شاشة تأسيسية توضّح حالة التوافق.
- لا يُشترط دعم ARCore لتثبيت التطبيق وتشغيل الشاشة الأساسية.

## ما الذي لم يُنفذ بعد؟
هذه ليست نسخة قياس مكتملة، ولا تحتوي بعد على:
- بث الكاميرا الحي أو تثبيت نقاط القياس.
- حساب المسافات أو المساحات أو الزوايا.
- قياس العمق أو الميل أو فرق الارتفاع.
- تسجيل فيديو مع طبقة القياسات.
- تحليل فيديو محفوظ.

## الخطوات التالية
1. بناء المشروع والتأكد من نجاحه.
2. إضافة معاينة كاميرا حية وصلاحياتها.
3. تنفيذ مسار ARCore للهواتف المتوافقة.
4. تنفيذ مسار بديل محدود للهواتف غير المتوافقة.
5. اختبار القياسات بأطوال مرجعية وتوثيق الخطأ قبل إعلان الدقة.

## البناء
يفتح المشروع في بيئة Android/Gradle مناسبة، ثم:
- APK: `:app:assembleDebug` أو `:app:assembleRelease`
- AAB: `:app:bundleRelease`

ملاحظة: يلزم تنزيل Gradle وAndroid SDK وحزم البناء في بيئة البناء. لم يتم إنتاج APK داخل هذه الحزمة.
